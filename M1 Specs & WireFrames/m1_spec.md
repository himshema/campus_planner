# Campus life planner

This platform will help students and other people at the campus be able to keep track of their tasks, activities, and schedules, hence simplifying time allocation. 

1. What are the main functionalities of this platform : 
This platform’s main focus areas are: 
 - Tasks/events/ group meetings, assignments, study sessions, 
 - Their durations/deadlines
 - Tags/ category
 - Search through the tasks

2. Data-storage structure/ Data model: 

 - Id: each record’s unique identifier
 - Title: type: string, name of the activity
 - dueDate:  timestamp
 - Duration: timeStamp
 - Tag: tag description, type: string
 - createdAt: type: timeStampt
 - updatedAt: type: timestamp
 - completed: datatype: boolean, False by default

3. a11y Accessibility plan
 - Allow Keyboard navigation 
 - Ensure visual clarity, even under high-contrast resolutions
 - Responsive across all devices
